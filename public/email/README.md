# Gmail signature — France Inside

Corporate signature (no personal name, phone, or photo) — brand name "France Inside" linking to Inside.paris.

## Install in Gmail

1. Open `signature.html` in a browser.
2. Select the whole signature block and copy it (Ctrl/Cmd+C).
3. In Gmail: Settings (gear icon) → **See all settings** → **General** tab → **Signature** → **Create new**.
4. Paste the copied block into the signature editor.
5. Scroll down and click **Save Changes**.

`france-inside-signature.txt` is a plain-text fallback for places that don't accept HTML (e.g. mobile Gmail signature field).
